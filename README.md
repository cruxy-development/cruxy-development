## What is Cruxy?

Cruxy is a unified AI platform. You hit **one API** — Cruxy decides which model handles the request based on complexity, cost, and latency, so you never pick a model again. Built India-first from the ground up: 20+ Indic languages, UPI-native billing, and context that understands GST, festivals, and IRCTC.

| **Cruxy Guard** | GitHub PR review bot |

---

## Models

| Model | Tier |
| --- | --- |
| **Kavi** | Premium — the heavy lifter |
| **Vaani** | Balanced — the default |
| **Mira** | Mini — fast and cheap |

The auto-router reads the prompt and sends it to the right one. Simple ask → Mira. Deep reasoning → Vaani or Kavi.
